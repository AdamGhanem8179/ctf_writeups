## TL;DR (Abstract)

The challenge provides a Rockstar esoteric language script containing song lyrics that require specific interactive user inputs to satisfy conditional statements. By analyzing the source code logic (or bypassing the input checks), the program executes a series of print instructions that output decimal ASCII values. A custom Python decoding script was written to parse these numerical codes and reconstruct the plaintext flag.

## Challenge Description

> I wrote you another song. Put the flag in the flag format: `academy{...}`

## Thought Process & Walkthrough

### 1. Initial Reconnaissance

Inspect the provided lyrics file:

* **Syntax:** Written in the **Rockstar** esoteric programming language, similar to `mus1c`.
* **Flow Change:** Unlike previous iterations, running this directly prompts the user for interactive input:
  * `Listen to the music` (`input()`)
  * `If the music is a guitar` (checks if the input equals the poetic number variable `a guitar`, which evaluates to `136`)
  * `Listen to the rhythm` (`input()`)
  * `If the rhythm without Music is nothing` (checks if `rhythm - Music == 0`, meaning `rhythm == 1970`)

### 2. Decoding Logic & Python Extraction

Rather than navigating interactive prompts or modifying the Rockstar code in the web interpreter, the output sequence of ASCII values generated by the print statements was parsed.

The decimal sequence printed by the program's output branch:

```text
66
79
78
74
79
86
73
```

A Python script was written to decode the numerical values into their corresponding ASCII string:

```python
# solve.py

ascii_codes = [66, 79, 78, 74, 79, 86, 73]

decoded_chars = [chr(code) for code in ascii_codes]
flag_inner = "".join(decoded_chars)

flag = f"academy{{{flag_inner}}}"
print(f"[+] Recovered Flag: {flag}")
```

Running the script:

```bash
python3 solve.py
```

Output:

```text
[+] Recovered Flag: academy{BONJOVI}
```
